资源返回不等于落盘。宿主暂不能落盘时，继续view_image读图并完成选题、日期、逐目标比较及全部语义。保留source_assets.json：schema="math-c-source-assets-v1"、source_commit、assets；每项含question_id、source_path、sha256、size、output_path、role。manifest只列实际落盘成员，欠缺项写pending_component=source_assets。仅缺源字节时，恢复包标semantic_analysis_complete=true、asset_materialization_complete=false，交本地按同版原文件装配，不重做分析或冒称完整业务ZIP。

本地用kaoyan-math-web-recovery保全原件，按实际错误修复并从resume_from补缺，必要时本地补语义，复用可靠成果。保留package、题目、知识点和事件身份；跨版本只验证并重算受影响依赖，不改旧哈希。已绑定旧下载/版本的run保留，以可追溯修订或后继技术run完成，不覆盖或重复apply。完整独立单元可先处理，已提交部分只补后置步骤；最后重建合约业务包并走本科接收入口，不将恢复包改成功标记导入，也不以保存进度或修好工具冒称业务/学习完成。

项目职责与资格

只处理数学正式错题。目标用用户指定日期，否则用当地次日。本项目不自编替代题，不使用其他学科内容凑数。

先接收本科 `math-c-handoff-v1` ZIP；它固定包含 START_HERE.md、handoff.json、refs.json。handoff.json 必须证明B完整证据已审核、正式事件已读回、profile 已 accepted/noop、知识点页与短摘要已刷新、publication_current.status=PUBLISHED_CURRENT；其中 profile_updates 是该B审核事件的 audit-as-of 证据，不能冒充当前状态，latest_mcp_snapshot记录交接生成时的快照；选题当前状态以本次library核实的MCP快照为准；refs.json 的 latest_snapshot 必须与 publication_current 相同。这份原包及其身份、成员哈希由本地 Bridge prepare --c-handoff 固定，网页不执行本地命令、不改写原包。网页先用 library(subject="math")取得当前快照，再调用 workflow(project=C,subject=math,target_date=明确日期,source_commit=本次当前版本)取得原生只读资格结果。C还必须读取本轮已正式化的B handoff、MCP当前记录，以及本轮A正式来源；若 run.dependency 明确为 no_new_packages_declared，则读取并原样保留该状态与原因，不伪造A来源。缺少当前分支要求的来源或版本不一致时报告阻塞。

按 workflow 返回的 collections 分批读取 anchors、eligible_candidates、concept_evidence、排除项和依据；原生返回哪些集合就按实际分页协议读至完整范围。程序负责资格分母和排除门禁，模型负责在真实证据上比较。若返回 NATIVE_MATH_DIFFERS_FROM_PUBLICATION 或快照未就绪，交本地刷新一致快照后再读，不要求 GitHub 上传，不绕过版本检查。

保持本科规则：Day 0–7 有真实活动或已交付的题排除，独立正确永久排除，同题修复属于独立通道。先从已审核并正式化的B逐点结果、当前A来源和MCP当前记录确定真实复习目标，再寻找能检验同一具体目标的真实旧卡。一个目标可对应多题，一题也可覆盖多个目标；不得预设正好五个知识点或强行一题一知识点。只涉及同名知识点不等于同一断点。成功时仍恰好5道真实题且ID唯一；不足5道如实报告，不重复、自编或放宽条件补足。

资格与语义都满足后，优先同一目标下最后一次真实学习活动最久远的候选。真实活动包括实际作答、复做、对照讲解/解析、正式复盘接触和明确复发；文件修改、入库、预处理、索引/Wiki重建、快照发布以及程序下载或校验图片都不算；本人实际看到原题或对照解析属于真实接触，须计入活动。每个候选必须打印实际最后活动日期与证据；确无记录就明确标为 unrecorded，不得拿卡面日期、mtime或入库日期冒充。每个复习目标还必须打印该目标在当前合格候选中的 source floor，也就是能达到的最早真实活动日期及来源；没有可核日期时如实给 unrecorded 和原因。
